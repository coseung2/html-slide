# Korean-first slide copy

한국어 발표 자료의 제목·본문·지표명을 영어 템플릿 번역처럼 쓰지 않기 위한 편집 규칙이다.
시각 스타일과 별개로, 관객이 한 번에 읽고 이해하는 한국어를 우선한다.

## 목차

1. 기본 원칙
2. 영어를 남겨도 되는 경우
3. 번역체를 만드는 패턴
4. 제목과 소제목
5. 스포츠 방송형 카피
6. 표·지표·UI 라벨
7. 전/후 예시
8. 최종 편집 점검

## 1. 기본 원칙

- 한국어 덱은 한국어로 먼저 문장을 만든다.
- 영어 원문을 그대로 놓고 단어별로 번역하지 않는다.
- 제목은 장면의 결론을 먼저 말한다. 설명은 본문으로 내린다.
- 명사만 길게 쌓기보다 주어·상태·수치가 드러나는 짧은 구를 쓴다.
- 기사 제목, 방송 자막, 경기 그래픽처럼 한 번에 읽히는 압축도를 목표로 한다.
- 짧게 만든다는 이유로 조사와 핵심 관계를 지워 뜻이 모호해지지 않게 한다.
- 디자인을 먼저 고정한 뒤 카피를 억지로 끼워 넣지 않는다. 실제 한국어 줄 길이로 레이아웃을 잡는다.

## 2. 영어를 남겨도 되는 경우

다음은 영어가 관객의 읽는 속도를 실제로 높일 때 유지할 수 있다.

- 널리 쓰이는 약어: `EPL`, `VAR`, `xG`, `AI`, `UI`, `HTML`
- 팀/종목의 짧은 코드: `MCI`, `ARS`, `LIV`
- 공식 브랜드·제품명: 고유 표기가 중요한 경우
- 원문 인용: 인용임을 분명히 표시한 경우
- 출처·메타데이터: 검색 가능성을 위해 원문 철자가 유용한 경우

영어가 단지 더 "프로 같아 보인다"는 이유는 유지 근거가 아니다.

의도적으로 유지한 노출 문구는 해당 요소나 부모에 `data-copy-en-ok`를 붙인다.
이 표시는 검토가 끝난 예외 한 곳을 뜻하며, 슬라이드 전체 면제 용도가 아니다.

## 3. 번역체를 만드는 패턴

### 추상 동사로 끝내기

피한다:

- `득점 레이스가 상위권을 설명한다`
- `5라운드가 우승 경쟁을 재검증한다`
- `이번 결과가 새로운 시그널을 보여준다`

바꾼다:

- `득점왕 경쟁, 홀란이 한 발 앞섰다`
- `맨시티, 3점 차 단독 선두`
- `5라운드 핵심 정리`

### 영어 명사 덩어리의 어순 보존

피한다:

- `상위 6 시장 리포트`
- `타이틀 레이스 3포인트 갭`
- `다음 업 매치`

바꾼다:

- `상위권 판도`
- `선두 격차 3점`
- `다음 경기`

### 같은 의미를 이중으로 말하기

피한다:

- `현재 시점에서 지금의 순위`
- `핵심 포인트 요약 정리`
- `다음 예정 경기 일정`

바꾼다:

- `현재 순위`
- `핵심 정리`
- `다음 경기`

## 4. 제목과 소제목

제목은 1초 안에 장면의 역할이 보이게 쓴다.

좋은 방향:

- `맨시티, 3점 차 단독 선두`
- `브라이턴, 아스널에 3–0 완승`
- `승점 9 동률권, 득실차가 가른 순위`
- `6라운드, 상위권 판도를 가를 첫 고비`

피할 방향:

- `TITLE RACE`
- `THE PACK`
- `MARKET REPORT`
- `새로운 판도가 시작되는 순간을 설명하다`

소제목은 제목을 다시 말하지 말고 수치·근거·맥락을 보탠다.

예:

```text
맨시티, 3점 차 단독 선두
5경기 전승 · 13득점 5실점
```

## 5. 스포츠 방송형 카피

스포츠 그래픽은 영어가 아니라 **압축된 정보 구조**에서 방송 느낌이 난다.

권장 어휘:

- 순위: `단독 선두`, `2위 유지`, `상위권`, `동률권`, `득실차 우위`
- 경기: `완승`, `신승`, `무승부`, `역전승`, `결승골`, `무득점`
- 격차: `3점 차`, `득실차 +11`, `1골 차`
- 흐름: `전승`, `무패`, `2연승`, `첫 패`, `반등`
- 예고: `다음 경기`, `주요 경기`, `맞대결`, `첫 고비`

선수 이름은 한국 매체에서 널리 쓰는 한글 표기가 있으면 관객용 카피에 그 표기를 쓴다.
원문 철자는 출처, 접근성 텍스트, 데이터 필드에 보존할 수 있다.

## 6. 표·지표·UI 라벨

한글이 더 빨리 읽히는 일반 라벨은 한글로 쓴다.

| 영어 템플릿 | 한국어 권장 |
|---|---|
| POINTS | 승점 |
| GOALS | 득점 |
| GOAL DIFF. | 득실차 |
| FORM | 최근 흐름 |
| RESULTS | 경기 결과 |
| NEXT UP | 다음 경기 |
| TOP SCORERS | 득점 순위 |
| SIGNAL | 핵심 정리 |

`W-D-L`처럼 표 공간이 매우 좁고 관습적으로 쓰이는 축약은 유지할 수 있다.
다만 관객이 초등학생이거나 비전문가라면 `승-무-패`가 더 낫다.

## 7. 전/후 예시

### 스포츠 리포트

Before:

```text
TOP SIX MARKET REPORT
TOP 3 POINTS
```

After:

```text
EPL 5라운드 상위권 판도
상위 3팀 승점
```

### 선두 경쟁

Before:

```text
TITLE RACE
3 POINT GAP
```

After:

```text
맨시티, 3점 차 단독 선두
아스널 12점 · 맨시티 15점
```

### 다음 경기

Before:

```text
NEXT UP
FIRST REAL TEST
```

After:

```text
6라운드 주요 경기
상위권 판도를 가를 첫 고비
```

### 일반 발표 자료

Before:

```text
KEY TAKEAWAYS
What this means for our workflow
```

After:

```text
핵심 정리
업무 흐름에서 달라지는 점
```

## 8. 최종 편집 점검

- 제목만 훑어도 덱의 흐름이 한국어로 자연스럽게 이어지는가?
- 영어를 지웠을 때 정보 손실이 없는 일반 라벨이 남아 있지 않은가?
- 영어를 남긴 각 항목에 약어·브랜드·인용 등 분명한 이유가 있는가?
- 한글 제목이 영문 원문의 어순을 그대로 따라가지 않는가?
- `~을 설명한다`, `~을 보여준다`, `~을 재검증한다` 같은 추상 동사를 더 직접적인 표현으로 바꿀 수 있는가?
- 스포츠 자료라면 국내 기사·중계 자막에서 실제로 쓸 법한 표현인가?
- 선수·팀 이름 표기가 한 슬라이드 안에서 한글/영문으로 흔들리지 않는가?
- 줄바꿈이 디자인 균형이 아니라 의미 단위에 맞춰져 있는가?
- `python tools/copy_lint.py deck.html --strict`가 통과하는가?

카피 린트 통과는 자연스러운 문장이라는 인증이 아니다. 마지막 품질 판정은 위 질문을 이용한 사람의 편집 검토다.
