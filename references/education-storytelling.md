# Elementary lesson visual storytelling

Use this guidance for elementary lessons where students need to understand people, places, movement, evidence, and cause-and-effect rather than merely read a summary.

## Choose the visual by the thinking task

- Actor, viewpoint, or decision: use character-callout. Use character-focus for one actor and character-duel for a clearly contrasted pair.
- Spatial movement, invasion, retreat, migration, travel, or expansion: use map-route on map-focus.
- Surviving artifact, building, document, or photograph: use the ordinary image visual as evidence.
- Ordered explanation without meaningful geography: use process or timeline instead of forcing a map.

Do not add every visual type to every slide. One slide should still communicate one point.

## Character callouts

Character illustrations are pedagogical representations, not evidence photographs. Use reviewed local raster assets and keep the figure visually subordinate to the learning point.

Every character-callout requires speechKind and speechLabel. Use quotation only for words supported by a source. Use paraphrase for teacher-authored simplification and label it visibly, for example "수업용 재구성". Do not put invented dialogue inside quotation marks and present it as a historical utterance.

A useful live beat is actor first, then speech-reveal. Static, print, reduced-motion, and no-JS frames must show the complete callout.

## Geographic routes

Use an actual or historically appropriate reviewed raster map whenever the spatial relationship matters. Coordinates in map-route are percentages of the displayed map, so authors must place them by inspecting the actual asset rather than guessing from memory.

Each route has a labelled start and end, an optional curved arc, a semantic tone, and an optional traveler illustration. Optional map events can mark battles, sieges, landings, naval encounters, turning points, or notes; afterRoute binds an event to the route step that makes it meaningful. route-travel advances one route per presenter step. The curve is deliberately arced rather than a flat straight arrow; an illustrated traveler can follow the path and receive a small mid-route lift to create documentary-style motion without turning the slide into a game animation.

Keep labels to the minimum needed for the explanation. For elementary audiences, prefer 3-6 important place names on a map. Split a campaign across slides when routes overlap so heavily that students cannot follow the order.

## Historical evidence and accuracy

Maps, portraits, reconstructed illustrations, surviving artifacts, and documentary records have different evidentiary status. Preserve source/license information in slide sources. Do not use a modern photograph as if it showed the historical event itself. Do not imply that an illustrative rider, soldier, king, or civilian is a literal portrait unless the source supports that claim.

When the lesson needs both narrative and evidence, use separate beats or adjacent slides: first help students understand the event, then show what survives as evidence.
