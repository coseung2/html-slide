파일과 프로젝트

실행 명령은 파일 확장자보다 프로젝트 구조에 따라 달라집니다.

단일 HTML 예시

index.html구조·스타일·동작
파일 열기

간단한 화면은 별도 개발 서버 없이 확인합니다.
브라우저 기능에 따라 로컬 HTTP 서버가 필요합니다.

Next.js 프로젝트 예시

app/page.tsx페이지 코드
public/정적 자산
package.json명령·의존성
npm run dev

개발 서버에서 프로젝트를 실행합니다.

모든 웹앱이 Next.js인 것은 아닙니다. 먼저 README와 package.json의 실행 명령을 확인합니다.
