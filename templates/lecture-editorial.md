# 강의·개념 설명형 템플릿

이 문서는 `templates/lecture-editorial.html` 전용 가이드입니다.

사용자가 제공한 강의형 시안처럼 밝은 종이색 배경, 단일 강조색, 큰 예시 화면과 개념 설명을 결합하는 편집형 구성을 출발점으로 삼습니다.

## 적합한 용도

- 교사 연수
- 수업 자료
- 제품/기술 개념 설명
- 워크숍
- 프로젝트 회고
- 문제 → 원인 → 해결 구조의 발표

## 장면 문법

### 개념 + 큰 예시

왼쪽 또는 오른쪽에 짧은 제목/본문을 두고 반대편에는 실제 UI, 도식, 사례를 크게 배치합니다.

텍스트가 화면을 설명하고, 화면이 텍스트를 증명해야 합니다.

### 단계

4~5단계 정도의 흐름은 카드 묶음보다 얇은 선과 타이포 위계로 정리합니다.

각 단계는 한 문장으로 끝내고 긴 설명은 발표자가 말하도록 남깁니다.

### 원인 → 결과

원인 목록과 결론을 좌우로 나누면 긴 문장을 쓰지 않고도 논리를 보여 줄 수 있습니다.

### 전/후 비교

두 결과물을 같은 크기·같은 기준으로 배치합니다.

장식 차이보다 정보 위계, 간격, 상태, 우선순위가 어떻게 바뀌었는지를 보여 줍니다.

### 마지막 장

마지막 슬라이드는 새 정보를 더하지 않습니다.

발표 전체의 중심 문장 하나를 다시 크게 고정합니다.

## 시각 톤

- 밝은 종이색 또는 따뜻한 중성 배경
- 검정에 가까운 본문색
- 강조색 1개
- 얇은 선
- 과도한 그림자·그라데이션 최소화
- 카드보다 간격과 타이포로 구조 표현

## 모션

이 템플릿은 설명 순서를 보조할 때만 모션을 사용합니다.

적합한 예:

- 단계가 하나씩 진행됨
- 이전 화면이 개선 화면으로 바뀜
- 한 요소가 실제 대상 위에서 강조됨
- 원인 목록 이후 결과가 등장함

모션이 없어도 최종 프레임에서 모든 정보가 보여야 합니다.

## 출발점

`lecture-editorial.html`은 다음 레이아웃을 빠르게 재사용하기 위한 기준 시안입니다.

- 텍스트 + 큰 예시
- 상단 제목 + 단계 흐름
- 원인/결과 분할
- 전/후 비교
- 중심 문장 마무리

내용에 맞지 않으면 레이아웃을 버리고 새 장면을 설계합니다. 템플릿은 결과를 고정하는 규칙이 아니라 시작점을 줄이는 도구입니다.
