# 스포츠 방송형 리포트 템플릿

이 문서는 `templates/sports-broadcast.html` 전용 가이드입니다.

코어 규칙은 `SKILL.md`를 따르고, 여기서는 스포츠 리포트에만 필요한 정보 구조·사진 검수·표현 규칙만 다룹니다.

## 적합한 용도

- 라운드 결산
- 순위표
- 경기 결과
- 득점·기록 비교
- 다음 경기 예고
- 선수·팀 중심 데이터 리포트

## 시각 구조

### 사진과 정보는 분리

경기 사진, 선수 컷아웃, 엠블럼과 텍스트 정보를 같은 좌표 위에 억지로 겹치지 않습니다.

- 사진: 별도 미디어 영역
- 팀명/선수명: 별도 텍스트 영역
- 스코어/기록: 별도 정보 영역
- 엠블럼: 고정 크기의 전용 슬롯

`object-fit: contain`을 기본으로 사용하고, 실제 사진을 의도적으로 크롭할 때만 `cover`를 사용합니다.

### 비교는 같은 기준축

승점, 득점, 점유율처럼 길이로 비교하는 수치는 같은 분모와 같은 기준선에서 그립니다.

값이 15와 12라면 15를 100%로 두고 12를 80%로 표현하는 식으로 상대 크기가 왜곡되지 않아야 합니다.

### 한 장에 하나의 방송 포인트

한 슬라이드에서 동시에 순위·득점·다음 경기·선수 사진을 모두 설명하지 않습니다.

- 순위 변화
- 한 경기
- 한 선수 기록
- 한 비교
- 다음 라운드

중 하나를 중심 장면으로 잡습니다.

## 미디어 안전

### 실제 자산을 확인

URL이나 파일명이 경기 사진처럼 보여도 실제 픽셀을 확인합니다.

구분 예:

- 실제 경기 사진
- 선수 액션 이미지
- 팀 엠블럼
- 구단 그래픽
- 벽지/프로모션 이미지
- 사용 불가 또는 출처 불명

투명 PNG/WebP는 단색 배경 위에서 확인해 아래쪽 잔여 픽셀이나 다른 엠블럼 조각이 남아 있지 않은지도 봅니다.

### 사실과 이미지를 별도로 검증

레이아웃 검사가 통과했다고 해서 다음이 검증되는 것은 아닙니다.

- 경기 결과
- 해당 시즌/라운드 여부
- 사진 속 선수·팀
- 실제 해당 경기 사진인지
- 이미지 권리

이 항목은 출처 확인이 별도로 필요합니다.

## 한국어 스포츠 카피

스포츠 템플릿에서만 사용하는 도메인 표현입니다.

예:

- `TITLE RACE` → `선두 경쟁`
- `3 POINT GAP` → `3점 차`
- `NEXT UP` → `다음 경기`
- `POINTS` → `승점`
- `GOALS` → `득점`
- `GOAL DIFF.` → `득실차`
- `FORM` → `최근 흐름`

제목은 직역형 명사 묶음보다 실제 국내 스포츠 기사·중계 자막처럼 씁니다.

예:

- `맨시티, 3점 차 단독 선두`
- `같은 9점, 득실차가 가른 순위`
- `브라이턴, 아스널에 3–0 완승`
- `다음 라운드, 선두권 첫 맞대결`

일반 한국어 카피 규칙은 `../references/korean-copy.md`를 따릅니다.

## 모션

모든 행을 차례로 움직이지 않습니다.

스포츠 리포트에서 유효한 모션은 주로 다음 두 종류입니다.

1. 같은 척도의 비교 막대가 한 번에 드러나는 장면
2. 한 기록이나 한 팀을 강조하는 짧은 포커스

라벨과 실제 수치는 모션 전에도 읽을 수 있어야 합니다.

## 추가 QA

미디어가 많은 덱은 기본 린터 외에 미디어 QA를 함께 사용할 수 있습니다.

```bash
python tools/media_qa.py deck.html --out out/media-qa
```

이 검사는 이미지/텍스트 충돌, 잘림, 깨진 이미지, 안전 영역 이탈, 하단 컨트롤 가림 등을 여러 뷰포트에서 확인합니다.

## 출발점

`sports-broadcast.html`은 스타일을 복사하기 위한 기준 시안입니다.

그대로 내용만 치환하는 고정 템플릿이 아니라, 다음 특징을 재사용하는 것이 목적입니다.

- 어두운 방송 그래픽 톤
- 높은 수치 대비
- 큰 스코어/기록
- 순위표의 강한 수평 리듬
- 사진과 정보의 분리
- 다음 경기/핵심 정리로 끝나는 흐름
