# 템플릿

템플릿은 **코어 규칙이 아니라 선택 가능한 시작점**입니다.

`SKILL.md`의 레이아웃·타이포·강조 바인딩·정적 완성 상태·검증 규칙은 모든 덱에 공통으로 적용합니다. 반면 색상, 정보 밀도, 장면 구성, 도메인별 어휘는 목적에 맞는 템플릿을 선택하거나 새로 설계합니다.

## 현재 제공 템플릿

### 스포츠 방송형 리포트

- 파일: [sports-broadcast.html](sports-broadcast.html)
- 상세 가이드: [sports-broadcast.md](sports-broadcast.md)
- 어두운 방송 그래픽 톤
- 순위표, 스코어, 비교 수치, 일정, 사진/정보 분리 장면에 적합
- 경기·선수·팀 데이터가 많은 리포트용
- 스포츠 전용 표현과 미디어 검수 규칙은 이 템플릿 문서 안에만 둡니다.

### 강의·개념 설명형

- 파일: [lecture-editorial.html](lecture-editorial.html)
- 밝은 종이색 배경 + 한 가지 강조색
- 제목/개념 + 큰 예시 화면, 원인/결과, 단계, 전후 비교 장면에 적합
- 수업, 연수, 발표, 개념 설명 자료용
- 장식보다 정보 위계와 예시를 크게 보여 주는 편집형 구성

## 사용 원칙

1. 템플릿을 그대로 반복하지 말고 **내용의 핵심 관계에 맞춰 장면을 재구성**합니다.
2. 템플릿의 색상과 레이아웃은 출발점일 뿐, 모든 프로젝트에 강제하지 않습니다.
3. 한국어 카피는 [한국어 카피 가이드](../references/korean-copy.md)를 따릅니다.
4. 모든 결과물은 최종적으로 `tools/slide_lint.py`와 `tools/verify.sh`를 통과해야 합니다.
5. 템플릿별 특수 규칙은 해당 템플릿 문서에만 둡니다.

새 템플릿을 추가할 때는 코어 README에 도메인 세부 규칙을 늘리지 말고, 이 폴더에 HTML + 짧은 가이드를 추가합니다.
